# Polar Air Solutions — Proposal Mockups

Demo mockups created for a consulting proposal to Polar Air Solutions, an HVAC contractor in Mobile, AL.

**These are not live sites or live accounts.** All numbers (review counts, follower counts, engagement, years in business) and all named testimonials are placeholders. The phone number uses the NANP-reserved 555 prefix. The license number, email, and contact details are clearly bracketed placeholders.

## What's in the package

| File | What it is |
|---|---|
| `index.html` | Landing page linking to the two mockups |
| `website.html` | Example Polar Air Solutions homepage with services, plan, testimonials, service area |
| `social.html` | Branded Facebook, X, and TikTok profile mockups with sample posts |

## Live preview

Once deployed to GitHub Pages, mockups will be visible at:
`https://<your-username>.github.io/<repo-name>/`

## Deploy to GitHub Pages

1. Create a new GitHub repo (public). Name it something like `polar-air-mockup`.
2. Upload all four files in this folder (`index.html`, `website.html`, `social.html`, `README.md`) to the repo.
3. In the repo, go to **Settings** → **Pages**.
4. Under "Build and deployment", set source to **Deploy from a branch**.
5. Select branch **main**, folder **/ (root)**. Click Save.
6. Wait 1–2 minutes. The URL appears at the top of the Pages settings page.

## What's intentionally a placeholder

- All review counts (e.g., "[#,###]" instead of "400+")
- All star ratings (e.g., "[#.#★]" instead of "4.9★")
- All four testimonial cards (clearly styled with dashed orange border + striped background)
- All Facebook follower/like counts
- All X follower/following counts and tweet engagement (replaced with em-dash "—")
- All TikTok follower/like/view counts (replaced with em-dash)
- "Years Local" badge ("[##]" instead of "17+")
- License number, email, "since 2008" claims
- Phone number uses 555-01XX (NANP-reserved fictional prefix)

Every placeholder is bracketed `[like this]` or shown as `—` so it's visually obvious nothing is being claimed as real.

## Before going live

When the owner approves the design and signs the proposal, every placeholder gets replaced with verified real data:

- Pull real review count and rating from Google Business Profile / Birdeye
- Source 4+ recent positive testimonials with explicit permission to use names
- Verify Alabama HVAC license number and current status
- Confirm real business phone, email, and physical address
- Confirm and verify "years in business" claim against state records or owner's records
